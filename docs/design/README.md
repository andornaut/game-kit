# Design

Each area has a short design summary and an index of its work items. The [README](../../README.md)
remains the detailed API, migration and verification reference. Work items and their convention
are in [docs/work/](../work/README.md).

| Area                        | Covers                                                                                                                                | Reference                                                                                                                                                        |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [mechanisms](mechanisms.md) | Pure game mechanisms: clock, motion, randomness, collections, achievements, utility scoring, terrain, text metrics and art primitives | [Modules and environments](../../README.md#modules-and-environments), [Terrain](../../README.md#terrain)                                                         |
| [input](input.md)           | Press, hold, scroll and gesture state, Phaser input guards and delegated DOM hold and page presses                                    | [Explicit pointer-release actions](../../README.md#explicit-pointer-release-actions)                                                                             |
| [ui](ui.md)                 | Button layout and presentation, focus, the HTML UI layer, modal isolation and the crash screen                                        | [High-density game UI](../../README.md#high-density-game-ui), [Dialog-subtree isolation](../../README.md#dialog-subtree-isolation)                               |
| [loading](loading.md)       | Loader policy, required-loading attempts, progress bars and the loading-failure presentation                                          | [Required loading failures](../../README.md#required-loading-failures)                                                                                           |
| [view](view.md)             | Fit, render scale, dimming, page frame turn and Phaser view adapters                                                                  | [Modules and environments](../../README.md#modules-and-environments)                                                                                             |
| [pwa](pwa.md)               | App window, install, offline play, service worker, precache, updates and save storage                                                 | [Build output](../../README.md#build-output)                                                                                                                     |
| [build](build.md)           | Vite configuration and plugins, reduced Phaser builds, build identity and security headers                                            | [API namespaces and migration](../../README.md#api-namespaces-and-migration)                                                                                     |
| [packaging](packaging.md)   | Public namespaces and exports, checks, CI, release archives and consumer proof                                                        | [Standalone verification](../../README.md#standalone-verification), [Release artifacts and consumer proof](../../README.md#release-artifacts-and-consumer-proof) |
