## Criteria

- Optionally emit one versioned group recipe alongside an unchanged grouped
  update. The recipe preserves canonical member order, type, size and SHA-256.
- Read member bodies through a supplied storage port and verify them and the
  final archive before sending the existing digest-addressed response.
- Preserve the updater contract, the 100-unit cap and support for earlier
  clients. Hosting, routing, retention and actual object removal belong to
  each game.
