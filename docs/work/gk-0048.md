## Criteria

- Install cleanly from the same digest-addressed archives that stage updates.
- Emit no separate copy of explicitly archive-only members. Keep direct
  bootstrap and site resources available and retain full offline coverage.
- Verify archive bytes and deployment identity before selecting the build.
  Preserve current-session pins, save protection and update activation rules.
- Coordinate game-owned group boundaries, physical asset inventory and
  first-install, update and offline qualification with each game's Tech owner.

## Outcome

Published in [GameKit 0.70.0](https://github.com/andornaut/game-kit/releases/tag/v0.70.0).
Chromium cold-installed from prebuilt groups with archive-only members absent
from the origin. Subsequent updates reused unchanged groups. The native proof
also covered offline reload, save before activation and an older open tab
keeping its pinned build. Each game adopts through its normal delivery.
