## Scope

Verify and package one pinned source snapshot, identify consumer proof by its actual scope
and refill the npm cache only for a confirmed cache miss.

## Criteria

- A working-tree check cannot produce a commit-stamped release archive.
- Release source, test result and package provenance refer to the same commit.
- Consumer receipt names identify which games the command actually checks. Document how
  the separate Ada evidence combines with Archie and Chibi.
- A non-cache install failure retains its diagnostic and does not trigger an online retry.

## Outcome

The release gate verifies and packages one committed archive. Development checks compile an unstamped distribution. Receipts identify the games checked, and only a confirmed cache miss triggers a refill. Fifty-one focused checks and the pinned packaging smoke checks passed.
