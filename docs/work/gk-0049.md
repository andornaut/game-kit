## Criteria

- Detect unavailable Service Worker or Cache Storage before starting the
  production installer or game.
- Stop the existing loading progress and show one readable failure panel with
  no action for missing browser capabilities. Keep Retry for recoverable
  installer failures.
- Use the same startup path in every game with its existing layout and progress
  lifecycle. Preserve saves, update activation and development launch behavior.
