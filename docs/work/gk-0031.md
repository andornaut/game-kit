## Scope

Apply ring-free focus, press and selection styling to the shared and loading-safe game
buttons. Keep caller-owned skins and styles and the asset-independent Retry path.

## Criteria

- No state adds an outline, border ring or ring-shaped shadow. Ordinary persistent borders
  and distinct disabled styling remain.
- Focus is visibly indicated by the face, text or icon, including in forced colours.
  Preserve focus order, native activation and return to the opener.
- Verify shared text and icon controls, crash buttons and loading Retry in a native browser.

## Outcome

Standard game buttons, crash actions and loading-safe Retry use a visible face or text cue on keyboard focus. Chromium checks covered keyboard and pointer modality, selected icons, disabled appearance, forced colours and stylesheet-free Retry. Sixty-one adjacent tests passed.
