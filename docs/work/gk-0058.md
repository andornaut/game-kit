## Criteria

- A slider form row with a stepped value and a set number of steps, left and
  right keys, and drag or tap on the track.
- The value word sits in the row's value column, right-aligned on ink where
  the game asks. The row has a single 16x16 icon slot.
- Game-supplied track and thumb art at locked sizes, whole-unit geometry with
  the projection hook.
- Fill-only focus and press with forced colours, and an available or refused
  state that plays the game's refusal cue.
- Reference: Archie settings view and HUD settings slider.
