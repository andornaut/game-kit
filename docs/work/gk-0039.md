## Scope

In a standalone Chrome app, returning focus to an already-visible Start
document did not trigger discovery. Returning from play to Start on the same
document found the deployed update.

## Criteria

- Feed window focus into the existing ordinary discovery scheduler.
- Preserve cooldown, coalescing, eligibility, explicit activation and saves.
- Remove the focus listener on disposal.

## Outcome

Window focus now enters the existing update discovery scheduler. The focused
regression reproduced the missing wake and passed after the change. The
first Start test on a deployed build with the patch remains a consumer check.
