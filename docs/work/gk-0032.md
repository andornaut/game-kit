## Scope

Prevent an obsolete Update now offer from switching the active build. Route startup storage
read failures through the applicable recovery flow and allow an explicit retry.

## Criteria

- Revalidate after the save callback and immediately before changing shared build state.
  Preserve the active build and any newer staged build when the offer is obsolete.
- Reload when the offered build is already active, and preserve save and activation guards.
- Distinguish a failed startup read from a missing record. Do not discard saved data or
  initiate a fresh install based on an unknown active build.
- Cover the stale-offer race and startup failure and retry with focused tests.

## Outcome

Activation revalidates the offered build after saving. Startup read failures use the existing Retry flow, which reads storage again before install. Eight causal failures on the baseline pass with the fix, alongside 125 adjacent PWA cases.
