## Criteria

- Cap specific-file update manifests at 100 files and grouped builds at 100
  groups. Report count overruns at build time.
- Form disjoint, stable groups from the final file discovery and address each
  archive by its own verified digest. Preserve the ordinary first-install path.
- Reuse verified groups across builds without per-file downloads or copies.
  Keep pinned clients and publish staged state only after the entire build is
  available to the controlling worker.
- Preserve retry, progress, save fences and single activation. Legacy builds
  keep their existing file and whole-archive readers.

Consumer adoption and publication are separate. Ada and Phoebe are designated
for specific-file updates.
