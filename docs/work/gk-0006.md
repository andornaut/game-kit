## Scope

A verified JSON response no longer fails on a header name outside a fixed list. Browser fetches
through Cloudflare carry `priority` and `server-timing`, which failed every first install of a
game with verified JSON.

## Criteria

- Headers without body semantics, including `priority` and `server-timing`, are ignored.
- `clear-site-data`, `content-disposition`, `content-location`, `content-range`, `refresh` and
  `set-cookie` still fail the response, as do the existing content-type, cache-control, vary, encoding,
  length, nosniff, redirect and source URL checks.
- 0.58.1 is released with the gate, consumer proof, exact-main CI and tag CI green.

## Decisions

- A rejection list of semantic headers replaces the allowlist, so a new CDN header cannot fail
  installs.

## Outcome

Replaced the header-name allowlist with the semantic rejection list, with tests for both.
Released as 0.58.1.
