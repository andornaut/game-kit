## Criteria

- Reduce active-play frame-interval p99 by at least 10% in Ada the Navigator, Archie and Chibi.
  Pin a representative baseline for each game before selecting the change.
- Compare exact before and after builds with matched replay, device, browser, renderer,
  resolution and settings. Use repeated runs in alternating order. Retain raw intervals
  and report nearest-rank p99 per run, baseline variability, and one diagnostic trace if needed.
- Preserve visuals, controls, simulation and save behavior. Game Tech owns game changes and
  normal delivery. GameKit owns shared changes supported by measured attribution.
- Verify the deployed revision contains the qualified change. Keep lab callback cadence,
  physical-device results and local CPU or raster measurements distinct.

## Outcome

The user retired the common 10% target. Keep the baseline, replay and trace
evidence for future investigations. Frame-time p99 remains a measurement for
reproducible stalls.

Ada Tech continues the separate scene-stall investigation. Archie can revisit
pacing if a normal-build comparison shows a repeatable visible benefit that
justifies the maintenance. Further Chibi benchmarking needs a reproducible
stall on a representative device.
