## Criteria

- Serve a listed network cache miss only after the decoded size and full SHA-256
  match the manifest of the client's pinned build.
- Reject incomplete or redirected responses. Preserve verified cache hits,
  verified JSON, unlisted networking, intentional installer bypass and
  whole-build archive routing.

## Outcome

The router verifies an ordinary listed network miss before returning the
original response. A verified response remains usable if its cache write fails.
The worker cases cover mismatched size or digest, redirects, and partial
responses while keeping the client's previous build pinned.
