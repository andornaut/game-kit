## Criteria

- A grouped install or staging whose device sound format changes between
  sessions recovers on the next launch, as the ordinary install path does,
  instead of failing until the next deploy.
- Press-area clamping measures each member's layout position, so a refusal
  shake that is playing does not shift the clamp.
