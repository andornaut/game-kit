## Scope

Adopt the shared design and work file policy: `docs/design/` area files with work-item index
tables, the `docs/work/` convention, and a CI split so docs-only changes skip tests and the
release build.

## Criteria

- `docs/design/README.md` lists every area; each area file has a summary and an ID, title and
  link index table with no status column.
- `docs/work/README.md` states the front matter, sections and editing rules.
- CI classifies changed paths. Lint always runs; the test and release-build job is skipped only
  when every changed path is under `docs/`, and runs for tags, new branches, forced pushes and
  anything it cannot classify.

## Decisions

- Finished history is not backfilled into work files; the README and git history keep it.

## Outcome

Added the design index, eight area files and the work convention. CI gained a `changes` job,
a separate `lint` job and a `verify` job that is skipped for docs-only changes.
