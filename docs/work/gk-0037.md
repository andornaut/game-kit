## Scope

Keep shared pointer refusal inside the caller's current action scope. Give configured
loading-safe Retry visible pressed feedback.

## Criteria

- Native pointer refusal and the held action respect current caller admission.
- Keyboard activation and refusal semantics stay intact.
- A trusted press visibly changes configured Retry paint in normal and forced colours.
  Preserve sizing, single-flight retry, keyboard containment and disposal.

## Outcome

Native pointer refusal requires a resolved action. Configured Retry visibly responds to a press while keeping its size and activation behavior. Both causal regressions failed on the baseline. The fixes passed 87 focused tests and Chromium pointer, forced-colors keyboard and strict CSP checks.
