## Scope

Apply the workspace memory ceiling to owned stock checks, browsers, packaging and consumer
proof launchers. Keep CPU, worker, admission and isolation limits.

## Criteria

- All owned container launch paths enforce the 4 GiB ceiling.
- Verify the cap in Docker on the affected launch paths and qualify the exact package checks.

## Outcome

Stock and committed-artifact launchers enforce the 4 GiB ceiling. Stock keeps valid smaller
limits. Docker reported 4294967296 bytes and four CPUs on both default launch paths.
Isolated ShellCheck and eight runtime tests passed.
