## Scope

Preserve focus restored by a discrete pointer-release touch action when the browser retargets
the ensuing compatibility mousedown. Keep modal callbacks and focus ownership with callers.

## Criteria

- A native touch Cancel restores and retains focus on the exact invoking control.
- Unrelated mouse, keyboard, assistive activation, drag and continuous input retain their
  behavior. The original action dispatches once.

## Decisions

Use the shared pointer-release binding. Keep any suppression restricted to the matching gesture.
