## Criteria

- Allow the game to arm and release the browser Back guard at a caller-selected boundary.
- Release the close watcher and unwind only the currently owned fallback history entry.
- Preserve other history entries, keyboard Escape handling and existing caller behaviour.
- Verify transitions between gameplay, Home and foreground history without game-specific rules.
