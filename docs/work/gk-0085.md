## Criteria

- Group crowded modules by cohesive responsibilities with clear dependencies.
- Keep public imports and behavior stable while clarifying private interfaces and conventions.
- Verify source, compiled exports and the affected module boundaries.

## Outcome

Grouped DOM UI, browser PWA, pure UI and Vite build modules by responsibility. Tests and
stylesheets moved with their modules. Explicit imports replaced two internal UI barrels, and
ESLint checks import direction and private-module access in the new areas. Public subpath names
and declarations remain compatible.
