## Scope

Provide shared native construction and discrete action behavior for standard text and icon
buttons. Reuse the existing layout, skin, availability and gesture mechanisms. Keep each game's
skin, names, placement, navigation and action callbacks in the caller.

## Criteria

- A native button supports text and named icon content with distinct focus, pressed, selected
  and disabled states. Keyboard, pointer, touch, hold and forced-colors behavior are qualified.
- The loading Retry path remains usable with unavailable styles, art or fonts. Preserve
  cancellation, availability, modal isolation and focus restoration.
- Existing APIs and game-specific continuous, drag, slider and editing paths retain their
  contract. Publish one verified consumer entry point and document the caller adapter boundary.

## Decisions

Reuse the current gesture lifecycle and keep game-specific styling parameters explicit.

- D1 (user, 2026-11-22; answers gk-0026-release-order): Ship the renderer first (Recommended)

## Outcome

Added the native standard text and icon button constructor and documented the caller's shared
root binding and guard contract. Crash and Retry share native construction. Native Chromium
qualified keyboard, touch hold, modal return and forced colours. Focused checks passed.
