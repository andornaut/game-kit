## Criteria

- Produce deterministic digest-addressed gzip packs and an index preserving
  every selected path, media type, byte size and full SHA-256.
- Require exact bytes and media type for explicit aliases.
- Bound and verify the encoded archive, decoded archive and requested member
  before serving the original path. An unknown path permits caller-owned
  fallback. An indexed member with invalid or unavailable bytes fails.
- Keep the origin adapter independent of service workers, update manifests
  and provider-specific routing. Games own storage and retained build roots.

## Outcome

Published in [GameKit 0.67.0](https://github.com/andornaut/game-kit/releases/tag/v0.67.0).
The writer and reader share a validated index with bounded gzip decoding.
The exact Archie scratch build verified all 123 listed files in 19 update
groups, including XML bitmap fonts. Game Tech owns the production route,
pack selection and deployment.
