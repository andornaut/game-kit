## Criteria

- A group may carry a sound format. A grouped first install and a grouped
  update skip groups for other formats and verify the stored groups against
  `installedManifest(soundFormat)`, as the ordinary install path does.
  `undefined` keeps installing every group.
- Grouped installs for one format download no bytes of another format's
  sound alternatives. Progress, completeness, staged promotion and the router
  read the same reduced manifest.
- Export a reader for members of the static group archive format, so a game's
  router serves archived members at their existing hashed URLs to every page,
  including an art gallery. No second archive parser in games.
- Preserve the ordinary first-install path, group reuse across builds, pins,
  retry, progress, save fences and single activation.

## Outcome

Published in [GameKit 0.72.0](https://github.com/andornaut/game-kit/releases/tag/v0.72.0).
Consumer adoption follows each game's normal delivery.

`updateGroup` builds split each group's sound alternatives into one group per
format, tagged `soundFormat` in the pointer. Launch reduces the pointer with
`installedPointer(soundFormat)` for grouped first installs and updates, so
progress, the sealed marker, completeness, promotion and the router name only
the device's groups. Both paths verify the stored members against
`installedManifest(soundFormat)` before activation or staging. `undefined`
installs every group, and untagged groups from earlier builds still install.
`createGroupArchiveMemberReader` serves verified members of the emitted group
archives at their original URLs at the origin. The installed router already
serves archived members to every page in its scope. The grouped browser
fixture now asserts that the M4A group is never requested.
