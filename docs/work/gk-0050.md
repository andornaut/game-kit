## Criteria

- A group may carry a sound format. A grouped first install and a grouped
  update skip groups for other formats and verify the stored groups against
  `installedManifest(soundFormat)`, as the ordinary install path does.
  `undefined` keeps installing every group.
- Grouped installs for one format download no bytes of another format's
  sound alternatives. Progress, completeness, staged promotion and the router
  read the same reduced manifest.
- Export a reader for members of the static group archive format, so a game's
  router serves archived members at their existing hashed URLs to every page,
  including an art gallery. No second archive parser in games.
- Preserve the ordinary first-install path, group reuse across builds, pins,
  retry, progress, save fences and single activation.
