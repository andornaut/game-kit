## Scope

Replace generic outlines in shared game controls with visible keyboard-focus styling.
Preserve caller-owned themes, graphic borders and the loading failure fallback.

## Criteria

- Pointer use shows the ordinary control graphic. Keyboard focus remains distinct and visible
  in ordinary and forced-colors modes.
- Focus order, keyboard activation, modal restoration, pressed, selected and disabled
  presentation retain their behavior.
- Verify affected shared surfaces in a native browser with keyboard and pointer input.

## Decisions

Use the existing shared controls and focus mechanism.
