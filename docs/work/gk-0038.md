## Scope

Review the published GameKit surface with Archie, Chibi and Ada Tech. Verify
that each game uses the current interfaces and applicable capabilities.
Deprecate superseded interfaces with precise migration notes and delete them
after their consumers migrate. Review the remaining public surface for naming,
argument order, dependencies, abstraction level and consistency, then ship
the interface changes and coordinated caller migrations.

Keep behavior and wire contracts stable. Implementation refactoring is deferred.
Games own their caller changes and delivery. Adoption of optional capabilities
depends on the game's needs and verification.

## Criteria

- Inventory exact public exports and consumer usage, including types, generated
  references, stylesheets, tests and build configuration.
- Prove replacement coverage or give a specific reason for keeping each
  retirement candidate. Qualify all three frozen consumer revisions before a
  breaking release.
- Remove obsolete public paths and any compatibility-only code or tests that
  have no remaining callers. Document the migration and publish a new immutable
  minor version.
- After retirement, review the surviving contracts by domain. Use dependency
  and context parameters before the subject, align signatures at the same
  abstraction level and keep consumer migrations measurable.

## Outcome

GameKit 0.64.0 removed 135 deprecated package paths and made four internal
launch names private. All three games passed against the same frozen release
archive.

The review covered all 143 canonical subpaths. The interface changes address
five demonstrated caller patterns: button read hooks, progress mounting, Back
guard dependencies, Phaser frame fitting, and crash screen installation.
The migration describes each signature and preserves the existing mechanisms.
