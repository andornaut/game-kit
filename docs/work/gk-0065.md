## Criteria

- With uiTheme roles and slots set, the crash screen's details text uses a
  readable slot pairing, never the ink colour on an ink face.
- A HUD disc ring can sit a set distance inside the disc frame, so a game
  draws its ring without per-state art.
- A pager's refusal cue shakes its buttons where no `--ui-unit` is set, at
  the default unit of 1.
- Callers that set no theme slots and no ring inset keep today's rendering.

## Outcome

Published in [GameKit 0.85.0](https://github.com/andornaut/game-kit/releases/tag/v0.85.0).
Consumer adoption follows each game's normal delivery.

Fixes and one opt-in token. Callers that set no theme slots and no ring inset
render as before. Consumer adoption follows each game's normal delivery.

- Crash details: the stack's face was `CrashColours.ink` in every case while its
  text inherited `textPrimary`, so a theme whose text slot is the ink colour,
  as Chibi's is, drew ink on ink. The stack now takes `textPrimary` on
  `cardFace`, the panel body's pair, each falling back on its own to the
  screen's text on `CrashColours.ink`. A game that sets `textPrimary` sets
  `cardFace` with it. Chibi can drop its `.crash-stack` colour override.
- HUD disc ring inset: `--ui-hud-disc-ring-inset`, whole base px, default 0,
  sits the fill layer's ring that far inside the edge in every state. The
  state's fill covers the band between the edge and the ring, as a spread of
  the layer's own fill, so the whole inside stays fill and no outline is
  drawn. The disc's box, face, icon box and press area do not move. Chibi's
  entry disc can draw its ring 1 unit inside the edge with the kit fill and
  drop the per-state art SVG.
- Refusal shake: `ui.css` read `var(--ui-unit)` with no fallback, so outside
  the UI layer the shake's `translate` was invalid and the control did not
  move. It now reads `var(--ui-unit, 1)`, so Archie's pager buttons shake with
  no unit set. The shake moves `translate`, not `transform`. The pager's
  refusal API is unchanged.
- Unchanged: main's and this change's stylesheets render the unthemed crash
  screen, with its details open and closed, and 30 HUD discs (five states,
  plain and painted, at units 1, 1.5 and 4) to identical pixels, and the same
  shake inside a set unit.
