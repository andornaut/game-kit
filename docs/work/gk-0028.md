## Scope

Diagnose stale installed sessions using released GameKit and exact old and current consumer
builds. Coordinate evidence with each game's Tech owner. Collect evidence and propose a
compatible correction if needed. Add a single check after reconnect or resume when the current
cooldown allows it.

## Criteria

- Distinguish continuous visibility, brief and eligible resume, offline launch and reconnect,
  partial staging, and migration from the preceding installed lifecycle.
- Verify the old active and candidate pins, update offer conditions, and explicit activation
  without clearing site data or changing saves.
- Separate controlled browser results from actual installed OS behavior. Record exact evidence,
  gaps and any next decision.

## Decisions

a throttled event until it expires while the page is visible and online. Keep continuous
foreground sessions event-driven. Preserve required-update priority, saves and explicit activation.
