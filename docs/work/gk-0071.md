## Criteria

- Placed form rows and sliders keep art-locked part sizes: the corner lands
  on the grid and the size is a whole number of art pixels, never stretched
  by snapping each edge separately.
- A placed list takes a gap per list and per row instead of a fixed stack gap.
- A one-action row variant hosts a single action whose press covers the row,
  or rows take a press margin per edge.
- Pressed rows can dip their art, as buttons do.
- Unplaced rows and today's defaults render as before.
