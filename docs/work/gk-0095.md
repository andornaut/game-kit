## Criteria

- Recover a verified active grouped build when a force reload bypasses its router.
- Bound automatic recovery and use the existing Retry path when it cannot proceed.
- Preserve normal startup, update selection, cache integrity and newer-save protection.

## Outcome

For a verified active grouped build, startup can make one ordinary reload when the expected
router is missing and the tab can record the attempt. If control is still missing, the existing
Retry screen handles the failure. A headed Firefox fixture recovered without archive downloads.
