## Scope

Support the shared Pause and Menu policy's Exit rule with one kit implementation: `canExitApp`
decides where a start screen offers Exit.

## Criteria

- `canExitApp` is true only in an installed app window that a script can close.
- 0.58.0 is released with the gate, consumer proof, exact-main CI and tag CI green, and the three
  Techs are told.

## Decisions

- No modal action-order helper: each game orders its own Pause and Menu actions.
