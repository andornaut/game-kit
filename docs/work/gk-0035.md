## Scope

Use one maintained local verification runner with development and release modes. Keep
working-tree verification and exact committed artifact proof as distinct modes.

## Criteria

- Share the container orchestration and validation steps.
- Keep existing entry points as thin adapters when needed by current callers.
- Preserve resource limits, source and archive provenance, cache handling and actual checks.
- Development verifies local changes without emitting a release archive.
