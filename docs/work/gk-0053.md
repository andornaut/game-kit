## Criteria

- An explicit `precachePlugin` option omits the decoded `archive-<sha>-0.bin`
  copies of compressed groups. Without it, builds keep emitting them for
  clients on GameKit 0.72.0 and earlier.
- `prepareBrowserLaunch` treats a missing `DecompressionStream` as an
  unavailable browser capability for grouped builds and shows the shared
  failure with no Retry.

## Outcome

`precachePlugin({ omitDecodedGroupCopies: true })` emits each compressed group
only at `/.game-kit/group-<sha256>.bin`, with the pointer and manifest
unchanged. Without it the decoded `archive-<sha256>-0.bin` copies are still
emitted. The option requires `updateGroup` and rejects `emitUpdateGroupRecipes`.
The `CLEANUP` marker now removes the copies and the option, in a minor
release, once every grouped game sets it.

`prepareBrowserLaunch` requires `DecompressionStream` with Service Worker and
Cache Storage on every production launch, grouped builds included. The pointer
that marks a grouped build is read only after startup, and every browser in
Vite's default build target provides the API, so one check before any request
is simpler and rejects no supported browser.
