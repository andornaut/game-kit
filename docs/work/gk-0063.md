## Criteria

- The loading failure and capability error panel takes a panel highlight
  token, so a game can draw its bevel row without editing the inline shadow.
- The crash screen's error details summary shows focus as a fill, not an
  outline, matching the cross-game fill-only focus rule. Forced colours keep a
  visible system focus.
- Unset tokens keep today's look, except the summary focus change.
