## Scope

Let game callers close an obsolete Update now prompt and continue play. Replacement updates
use normal discovery and require their own consent.

## Criteria

- Distinguish obsolete offers from failed saves, verification or activation.
- Preserve explicit Update now and the active/staged and newer-save fences.
- Preserve retry behavior for actual save and switch failures.
- Qualify the shared contract and send exact adoption guidance to all game Tech owners.

## Outcome

ObsoleteUpdateOfferError identifies the version that began a superseded switch. It leaves genuine failures on the existing rejection path. The 140 focused cases cover the distinction, overlapping offers and adjacent install, save and activation behavior.
